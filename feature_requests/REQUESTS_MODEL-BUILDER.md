# BVR Motion Viewer Feature Request Documentation

## Model Builder Module

This document tracks feature requests, suggestions and bug fixes for the BVR Motion Viewer related to the model builder module, from when they are requested to when they are built into the code.

**How to use it**

- Add each new request as a new row at the bottom of the table, with the date it was requested (d/mm/yyyy), the status `Request`, and a new number (#).
- Change the status to `Implementing` while it is being worked on, and to `Completed` once it is in the code.
- When a request is completed, the **Notes** column records how it was implemented (what changed, where, and the commit).
- To keep a line break inside a cell, use `<br>`. Every row must stay on one line.

**Status values:** `Request` · `Implementing` · `Completed`

Navigator marks ✓ / ◐ / ○.<br>**Save** (Ctrl+S) / **Save as…** (Ctrl+Shift+S) in the tab bar, model page and File menu (File → Save now saves whatever the current tab holds); • on the tab title for unsaved changes; closing asks Save / Discard / Cancel. Unapplied bones are saved without axes; older model files open as applied.<br>**Joints**: select two bones with applied axes together (Ctrl+click, or right-click → Add joint with) and Properties offers the definitions that fit them, in the right proximal → distal order (`joint_types_for`), then the general ones with Swap; Add joint dialog limited to applied bones. Knee/ankle presets removed from the interface.<br>Tests: `tests/test_model_builder_core.py`, `tests/drive_model_builder.py` (rewritten for the new flow). Commit `f3f206d`. |

# BVR Motion Viewer Feature Request Documentation

## Model Builder Module

This document tracks feature requests, suggestions and bug fixes for the BVR Motion Viewer related to the model builder module, from when they are requested to when they are built into the code.

**How to use it**

- Add each new request as a new row at the bottom of the table, with the date it was requested (d/mm/yyyy), the status `Request`, and a new number (#).
- Change the status to `Implementing` while it is being worked on, and to `Completed` once it is in the code.
- When a request is completed, the **Notes** column records how it was implemented (what changed, where, and the commit).
- To keep a line break inside a cell, use `<br>`. Every row must stay on one line.

**Status values:** `Request` · `Implementing` · `Completed`

| 1   | 10/11/2026 | Request | The model builder process for adding axes to a bone and connecting joints needs to change with respect to the ordering of processes. Currrently it asks to select the type of bone or joint you're building first. The current process I'd like would be: (i) Load a surface volume into the model builder (i.e. a similar approach to how the visualiser works); (ii) select from the dropdown what bone it is (e.g. femur, calcaneus etc.), with this including a 'general' option for cases not covered; (iii) once selected, the options for generating that bone coordinate system should become available; (iv) once selecting the desired method for creating the coordinate system for that bone, the approaches for these methods should become available (e.g. selecting a point, painting an area); (v) once all processes are done there should be some sort of apply button and then the option to save the model (save, save as). |       |
